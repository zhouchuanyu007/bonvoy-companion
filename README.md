# 万豪会员出行助手（暂定名）

本目录用于一个仅供个人使用的 Android App，暂定英文代号为 `Bonvoy Companion`。

当前阶段：全国目录与多源联网规划版 MVP。已切换为标准 Android Gradle 工程，并接入高德地图、万豪官方公开搜索、飞猪酒店/景点/交通/AI 搜索、全国酒店目录、酒店公开详情和按出发地生成行程。

最新需求以 [V2 需求清单](docs/requirements-v2.md) 为准；初版需求文档仅作为讨论记录保留。

## 产品目标

帮助万豪旅享家会员在预算、时间和会员权益约束下，完成三件事：

1. 选对目的地：根据出发地、预算、天数、同行人和兴趣找到有在营万豪系酒店的城市或区域。
2. 选对酒店：用地图、真实到手价、近期住客反馈、交通和设施信息做决策。
3. 少踩坑：把取消时限、会员权益、酒店临时关闭设施、积分和房券到期等风险提前提示出来。

它不重复万豪官方 App 的预订、支付和账户管理，而是做官方 App 不擅长的跨来源比较、个性化筛选和旅行决策。

## 首版功能假设

- 预算、时长和主题驱动的目的地推荐
- 目的地酒店地图与参考房价
- 酒店详情和 300 字以内、包含社交主帖及评论的多来源反馈摘要
- 不同价位、不同出行场景下的质量榜与性价比榜
- 酒店收藏、对比和官方预订深链
- 会员权益、积分、房券和取消时限的个人旅行面板

## 数据底线

- 价格必须标注查询日期、入住日期、房型、人数、税费和会员价口径，不能只显示一个没有上下文的“最低价”。
- 公开评论口碑必须可追溯来源和更新时间，样本不足时明确提示，不能用模型凭空补写体验。
- “万豪旗下”与“万豪直接管理”不是同一概念；本版本统一纳入集团品牌物业，但不在界面突出未核实的运营方标签。
- 优先使用官方接口、合作方授权数据或允许使用的数据源；不以绕过登录、验证码、反爬或会员权限的方式取得数据。
- 本 App 为非官方个人工具，不代表或隶属于万豪国际集团；公开发布前需重新评估商标、数据授权和隐私合规。

详细需求、功能优先级和数据可行性见 [V2 需求清单](docs/requirements-v2.md)、[飞猪联网接入说明](docs/flyai-integration.md)、[酒店详情数据说明](docs/hotel-detail-data.md)、[初版产品需求池](docs/product-brief.md) 与 [数据与合规说明](docs/data-and-compliance.md)。

## 当前可运行版本

- 安装包由本地构建生成到 `dist/BonvoyCompanion-0.11.0.apk`；`dist/` 不进入 Git，GitHub 发布请使用 Releases。
- 旧版安装包保留在本机 `dist/archive`，只用于回滚，不提交到源码仓库。
- Android 版本：最低 Android 6.0（API 23），目标 Android 15（API 35）
- 数据范围：151 个城市、852 家中国境内万豪系酒店
- 本地酒店详情：预装 739 家酒店详情记录，其中 739 家具备设施资料、733 家有房型资料；共 3,148 条飞猪与携程公开评论。其余酒店保留基础目录资料并在详情页按需联网获取
- 运营信息：酒店统一进入候选池，界面不再突出运营方或“未核实”标签
- 评论来源：飞猪/携程公开评价；社交评论云服务列入后续子任务
- 地图：高德地图 JS API；地点、地理编码和驾车路线通过高德 Web 服务
- 网络：飞猪 AI 开放平台、高德联网地图/路线、万豪官方公开搜索和用户主动触发的房价更新
- 隐私：收藏、对比、清单、酒店详情和价格覆盖数据均保存在本机或 APK 资产中

已实现：

- 首页改为地图、全国目录、地区榜单和行程入口，不再在首页重复行程规划
- 高德真实地图、全国城市选择、品牌/价位筛选；点击价格标签直接进入酒店详情
- 地图定位当前位置；重新选择城市时自动按该城酒店重新适配视野，从酒店详情返回仍保留进入前的城市、中心点和缩放
- 地图可按地址、商圈或景点搜索，使用高德地理编码/POI 定位，并展示约 12 km 内或最近的万豪系酒店

- 独立全国酒店目录：本地搜索、地区/品牌筛选、每家酒店的 150—300 字资料速评
- 酒店详情、收藏、四家酒店对比
- 飞猪订房按钮会先解析 `router.feizhu.com` 的真实酒店详情 H5，再构造 `tbopen://...h5Url=` 深链；优先交给飞猪旅行，无法处理时交给已安装的淘宝客户端直达酒店页
- 酒店详情可联网获取房型价格、设施、政策、周边 POI、酒店特色和公开评论，并保存在本机
- 飞猪、携程公开评论共同生成本地口碑摘要和非官网评分
- 地图无价酒店既支持本城逐家补价，也可在单店详情页只查询该酒店；价格标签直接打开酒店详情
- 按华东、华南、华北、华中、西南、西北、东北分区，并可在榜单内切换万豪、万怡、威斯汀、JW 万豪、福朋喜来登、丽思卡尔顿等子品牌的质量 Top 10 和性价比 Top 10
- 积分每万分价值速算、入住前确认清单
- 同时有现金价和积分价时，地图介绍栏与酒店卡片显示按当前积分估值换算的约当金额和现金差额；该值为估算，不代表官方兑换价值
- 酒店详情的“价格与权益”同时给出积分约当价值、现金差额和兑换判断；设施与政策已改为重点摘要
- 酒店地图卡片和详情页会估算“¥1,088 / 2 晚”飞猪闪促券相对直接订房的价差；用户确认酒店可兑换且周末不加价后，勾选结果会保存并在两晚行程总价中自动扣除节省金额
- 按城市从万豪官网同步现金价和积分房数量并分别展示；飞猪查价保持独立入口和本地缓存
- 行程页支持出发地、目的地、精确日期、自由文字兴趣和三档旅行节奏
- 行程支持备注、按预算和偏好推荐酒店、本地酒店切换与总花费联动；设置中的酒店偏好支持“性价比和质量平衡”与“别具一格”
- 行程增加独立餐饮卡片，接入美团酒旅 Skill，支持大众点评必吃榜相关餐厅、评分、人均、商圈、地址和营业时间；接口失败时回退到飞猪/高德，并明确标注来源
- 行程结果覆盖当地美食、自然风光和名胜古迹，增加 DeepSeek 复合攻略
- 高德路线使用 App 深链直接打开高德地图；地图往返保留城市、缩放和中心点
- 飞猪 AI 内容、结构化酒店/景点/交通事实和高德路线分别标注来源；AI 文字不冒充实时房态或用户原文

## 构建与安装

项目源码使用标准 Android Gradle 工程。本机 SDK、模拟器、JDK、Gradle、签名和 API 凭据统一放在 `local-env/`，该目录已被 `.gitignore` 排除，不会上传到 GitHub。

在当前机器上重新构建：

```powershell
.\build.ps1
```

构建脚本使用 Android Gradle Plugin 8.7.3、Gradle 8.9、Android SDK 35 和 JDK 17。找到本地签名配置时输出签名 APK；新协作者没有签名文件时输出未签名开发包。

首次在新机器上开发：

1. 在 Android Studio 中安装 Android SDK 35 和 JDK 17，或者让 `JAVA_HOME`、`ANDROID_HOME` 指向已有工具链。
2. 运行 `.\scripts\setup-local-env.ps1`，再编辑 `local-env/secrets.properties` 填入自己的 API Key；没有 Key 也可以构建，但地图和联网功能不可用。
3. 打开项目或运行 `.\build.ps1`。

更新已安装应用时必须保留本机签名文件 `local-env/signing/local-release.jks`，否则 Android 会将其视为不同应用。不要把该文件或 `keystore.properties` 发给协作者；每位维护者应使用自己的签名。

安装到已授权的 Android 设备：

```powershell
adb install -r .\dist\BonvoyCompanion-0.11.0.apk
```

如果手机直接点击 APK 安装失败，请先确认系统为 Android 6.0 或更高版本，并卸载之前的测试版本后再安装。仍然失败时，请记录系统显示的完整错误文字；必要时用上面的 `adb install` 命令复现。

## 仓库边界与 GitHub 协作

只提交源码、文档、测试和小体积内置数据。以下内容仅保留在本机，并已被 `.gitignore` 排除：

- `local-env/`：Android SDK、模拟器、JDK、Gradle、签名和 API 凭据
- `build/`、`app/build/`、`.gradle/`：可重新生成的构建产物与缓存
- `dist/`：APK、旧版安装包和校验文件
- `local.properties`：本机 SDK 路径

不要使用 GitHub 网页的“拖拽整个文件夹”方式上传，因为浏览器不会执行 `.gitignore`。应通过 Git 提交和推送：

```powershell
git add .
git status
git commit -m "Initial commit"
git push -u origin main
```

推送前运行 `git status --ignored`，确认 `local-env/`、`dist/` 和签名文件没有进入待提交列表。

## 当前限制

- 852 家酒店来自万豪公开搜索目录快照，目录时间与价格查询日期在 App 内展示；目录可能因官网更新、新增或摘牌而变化。
- 本次补充查询后，本地快照有 733/852 家酒店取得公开报价；新增 51 家。剩余 119 家在 2026-10-20 入住日期没有返回可售公开价格，不是库存或锁价，仍需换日期查询。
- 联网更新目前按当前城市触发，不自动爬取全国，也不保证任意时间可用；官方网站接口变化时需要重新生成同步脚本。
- 高德、DeepSeek、飞猪和美团凭据已从源码移出，构建时从 `local-env/secrets.properties` 注入。它们仍会进入 APK，可被逆向提取，因此公开分发 APK 前应轮换 Key，并把高价值接口迁移到受控后端代理。
- 行程中的酒店起价和景点/交通事实来自飞猪联网搜索，地图与驾车路线来自高德；飞猪 AI 文字是生成式建议。房态、票价、余票、营业时间和最终价格仍需以下单页和官方渠道为准。
- 全国酒店目录仍保留根据万豪官方介绍整理的“资料速评”，它们不与公开住客评价混算。飞猪公开详情会返回有限条评论，携程公开页通常只暴露少量评论；评论 API 未返回日期，因此界面不宣称这些评论都发生在近一年。
- 完整详情批量采集受飞猪接口限流和第三方匹配范围影响，当前 APK 预装 739 家酒店详情；剩余 113 家没有取得匹配的公开房型/设施详情，但仍有本地基础介绍，详情页可继续按需获取。批量脚本支持断点续采。
- 飞猪接入使用官方 `alibaba-flyai/flyai-skill` 对应的 MCP 端点和签名方式，只开放万豪酒店、景点、AI、火车和航班五个工具。酒店搜索接口未返回可核验的评论全文，因此没有把平台搜索摘要或 AI 文字冒充住客原文。
- 小红书公开搜索在当前网络直接返回平台风控（IP 存在风险），没有绕过验证码或登录限制。相关用户反馈收集、云存储与摘要流程已记录为 [后续子任务](docs/subtasks/guest-feedback-cloud.md)。
- 会员账户、积分余额、官方价格提醒和后台推送尚未接入。
- 美团 POI 数据开放接口文档要求 `appkey`、`appsecret` 和按接口授权的 `session`，当前提供的 Token 属于 AI Hub 酒旅 Skill，二者不能混用。App 已通过官方 `clawhub` 渠道调用酒旅 Skill；如以后要以 POI 接口批量同步评价，需要补充对应开放平台凭证。
- 飞猪官方 AI 搜索明确不提供双十一券类商品的适用酒店、库存和周末加价字段，因此 App 只计算价差并提示核验，不会自动宣称某酒店一定能兑换。
- 0.11.0 APK 需要通过 Gradle 构建、v1/v2/v3 签名、包内容和 DEX 桥接检查。当前环境的旧模拟器离线，仍缺一次目标真机的安装、定位权限和飞猪酒店直达确认；如手机报错，请提供完整错误文字或截图。
