# 数据与合规说明

更新时间：2026-10-19

## 1. 必须先确认的现实

这个产品最难的环节不是地图或 Android 界面，而是持续、合法、可解释地获得酒店、房价、评论和会员权益数据。

在没有官方接口或商业数据授权的情况下，不能承诺以下能力：

- 实时覆盖中国所有万豪系酒店的最低可订价
- 绕过万豪账户权限取得会员专享价或个性化房价
- 从禁止抓取的平台批量获取完整评论
- 精确预测某次入住一定升级或一定享受某项权益
- 保证地图缓存价格在用户点击时仍然可订

## 2. 建议的数据优先级

### 酒店主数据

优先来源：

1. 万豪官方酒店目录或授权合作接口
2. 酒店官方页面和酒店公开公告
3. 可合法使用的酒店基础数据供应商

必要字段：

- 官方酒店 ID、中文名、英文名、品牌
- 地址、坐标、城市、行政区和周边交通
- 营业状态、开业与翻新年份
- 品牌归属、管理方式及“是否已核实”
- 设施、房型、政策、官方联系入口
- 图文授权范围和来源

### 房价

优先级：

1. 官方 API 或合作方报价接口
2. 用户主动查询后显示且允许缓存/深链的公开报价
3. 经过授权的聚合数据源
4. 用户手动记录的价格，仅用于个人对比

每条价格记录至少包含：

- 查询时间与入住/离店日期
- 成人、儿童、房间数和房型
- 税前、税费、含税总价
- 早餐、取消政策、预付/担保条件
- 价格类型：公开价、会员价、积分价、积分加现金
- 来源与是否实时确认

### 评论

优先级：

1. 评论平台授权 API 或商业授权数据
2. 明确允许再利用的来源
3. 用户手动粘贴或导入的点评

不要默认“网页公开可见”就等于“可以批量抓取并二次加工发布”。使用前应核对平台条款、robots 规则、著作权和个人信息要求。

评论处理建议：

- 只保留决策所需的主题、时间、评分和短引用，不长期保存不必要的原文全文
- 摘要注明来源、样本量、时间范围和生成时间
- 区分酒店整体评价与具体房型、季节、装修阶段的问题
- 涉及员工姓名、房间号等可识别信息时做脱敏
- 发现来源冲突时展示分歧，不强行合成单一结论
- 不用 AI 生成不存在的评论、住客身份或体验细节

## 3. “万豪酒店”的口径

产品中应明确区分：

- **品牌归属**：是否属于万豪国际旗下品牌并参与万豪旅享家
- **管理模式**：万豪直接管理、特许经营、第三方管理或其他
- **营业状态**：在营、筹备、暂停营业、已摘牌
- **可订状态**：指定日期是否可预订

如果公开资料无法确认管理模式，应显示“未核实”，不能推断为直营。

## 4. 建议的更新频率

- 酒店基础信息和营业状态：每周至每月
- 设施、公告和管理方式：有变化时更新，至少每季度复核
- 评论摘要：每月或每季度
- 榜单：按月，节假日和大型活动前单独刷新
- 房价：按查询日期获取；无法实时获取时显示最近快照和官方查询入口

## 5. 非官方身份说明

当前定位为个人使用的非官方工具。若未来公开分发，应重新评估：

- 万豪及相关品牌的商标和视觉规范使用
- 酒店图片、地图瓦片、评论内容的授权
- 隐私政策、账号数据处理和删除机制
- 应用商店对旅行、金融和会员账户相关权限的要求
- 价格展示是否可能构成误导或未经许可的代理销售
