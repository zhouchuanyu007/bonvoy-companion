# 万豪额外积分闪促数据

“闪促酒店”在这里只表示预订后额外赠送万豪积分的活动酒店，不表示折扣房晚套餐，也不表示普通会员价。

## 当前数据状态

- 万豪官方最低房价 GraphQL 未返回 `bonusPoints`、额外积分活动或活动有效期字段。
- 飞猪酒店搜索接口当前只返回房价、坐标、详情链接等字段，不包含积分促销字段。
- 飞猪 AI 搜索明确提示其酒店数据不含营销活动、参与酒店或积分数量。
- 因此 App 不会根据酒店名称、会员价或房价差推断积分闪促。

## 支持的字段

实时酒店记录或本地 `points-promotions.js` 只有包含以下可信信息后才会显示：

```json
{
  "hotelId": "HOTEL_ID",
  "bonusPoints": 3000,
  "title": "预订额外赠送 3,000 积分",
  "validFrom": "2026-10-01",
  "validTo": "2026-11-30",
  "source": "万豪活动页",
  "fetchedAt": "2026-10-22T00:00:00Z"
}
```

## 后续数据源要求

如果需要覆盖“当前正在闪促”的全部酒店，需要获得能列出参与酒店、额外积分数量、活动日期和适用房价代码的公开接口或授权数据源。取得后再增加定时同步和本地快照，不使用 AI 推测名单。
