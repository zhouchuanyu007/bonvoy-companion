# 子任务：住客反馈云存储与持续更新

状态：未实现，等待云存储和服务端能力。

当前版本已从 App 界面移除“住客证据摘要”和手动评论摘要入口。保留本设计作为后续子任务：

1. 用户自愿提交入住反馈，明确授权保存范围和用途。
2. 服务端定期归集授权数据、飞猪/携程公开评价和经许可的社交内容。
3. 按酒店实体去重、识别一手入住、营销内容和无关讨论。
4. 生成可追溯的近期口碑摘要、主题分布与非官网评分。
5. 通过版本化数据集更新 App，保留样本量、来源、抓取时间和置信度。
6. 提供撤回、纠错和隐私删除流程。

该功能需要账号体系、云数据库、审核机制、隐私政策和服务端定时任务，不在当前离线 APK 内伪造实现。
