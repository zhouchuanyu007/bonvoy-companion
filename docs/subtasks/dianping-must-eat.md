# 大众点评必吃榜接入记录

## 当前状态

0.10.0 已通过美团官方酒店旅行 Skill 接入餐饮推荐。原生桥使用 AI Hub Token 调用 `clawhub` 渠道，行程页展示大众点评必吃榜相关餐厅、评分、人均、商圈、地址与营业时间；接口失败时回退到飞猪/高德公开搜索并明确标注来源。

美团点评 POI 数据开放接口同时要求 `appkey`、`appsecret` 和按接口授权的 `session`，与 AI Hub Skill Token 不是同一类凭证。当前没有把 Skill Token 发给 POI 接口，也没有抓取验证码页面或伪装请求。

## 继续接入所需信息

1. 正式 API 基础地址和完整路径。
2. 鉴权方式：密钥应放在请求头、查询参数还是签名串中。
3. 城市编码、榜单年份、页码和分页大小等请求字段。
4. 返回字段：餐厅名、菜系、商圈、地址、评分、上榜标签、榜单年份、营业状态和详情链接。
5. 调用配额、缓存要求、展示归属和商业使用限制。

## 接入原则

- 密钥只保存在 Android 原生层或后续服务端，不进入网页脚本、日志、截图或公开仓库。
- 页面明确显示榜单元年、采集时间与来源。
- 不在接口失败时把普通餐厅结果标注为“必吃榜”。
- 优先使用官方授权接口；不从验证码、登录页或反爬页面绕过限制抓取。

## 实现落点

- 原生网络桥：仅允许固定的官方主机和接口路径。
- 行程数据结构：`tripPlan.restaurants`。
- 页面模块：`renderRestaurantRecommendations()`。
- 当前回退数据：飞猪 `search_poi` 与高德 `place/text` 的餐饮搜索结果。
