# 酒店详情与住客口碑数据

更新时间：2026-10-19

## 当前 APK 内置范围

- 全国目录：852 家酒店、151 个城市。
- 酒店详情记录：739 家。
- 含房型/设施资料的酒店：739 家，其中 733 家有房型资料。
- 公开评论：3,148 条，其中飞猪 2,973 条、携程 175 条。
- 携程酒店页成功匹配：88 家。
- 价格覆盖：新增 51 家，当前 733/852 家有公开起价；119 家在本次日期无可用公开报价。

其余酒店在详情页点击“获取设施与住客评价”后联网获取，成功后保存到本机。批量采集脚本支持断点续采：

```powershell
node .\scripts\enrich-hotel-insights.js
node .\scripts\enrich-ctrip-reviews.js
```

飞猪接口存在明显限流；高并发会返回 HTTP 429。脚本使用低速、重试和断点保存，不建议绕过限流。

## 数据字段

- 酒店基础信息：地址、电话、等级、房间数、开业/装修时间、入住方式、特色说明。
- 房型：房型名、床型、面积/楼层、设施摘要、公开起价、早餐和取消政策。
- 设施：热门设施、交通、前台、商务、餐饮、康体等公开分类。
- 政策：入离时间、早餐、儿童、宠物、押金、加床和洗漱用品。
- 周边：交通、景点、餐饮和购物 POI。
- 评论：公开评论文本、来源和抓取时间。

## 口碑分

详情页的“本地口碑分”由本地规则根据评论中的正负主题、负面转折词和样本量计算，满分 10 分。它不是万豪官网评分，也不是携程、飞猪或小红书的官方评分。

## 已知边界

- 飞猪评论日期没有随接口返回；携程公开页也只展示评论正文，不能据此保证全部发生在近一年。界面明确显示“公开接口未返回评论日期”。
- 小红书公开搜索在当前网络返回 `300012 IP存在风险`，属于平台风控。未绕过登录、验证码或风控；App 内已移除评论导入入口，相关云服务流程记录在子任务文档。
- 携程公开页面通常只暴露 1—2 条评论；多数酒店的本地样本来自飞猪的 5 条公开评价。
- 酒店名称与第三方平台名称不完全一致时可能无法自动匹配；未匹配时保留万豪目录资料，并提示稍后联网重试。
- 房型价格是采集时公开页面的参考起价，不等于所选入住日期的锁价。
